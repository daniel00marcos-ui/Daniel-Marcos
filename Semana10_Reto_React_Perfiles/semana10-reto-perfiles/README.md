# Semana 10 - Reto React: perfiles

Cumple los cuatro puntos del archivo `RETO-semana10-dia01.md`: Vite + React JS, `src/components/Profile.jsx`, props `nombre` y `role`, y varios perfiles desde `App.jsx`.

## Ejecutar
1. Abrir la carpeta en Visual Studio Code.
2. Abrir Terminal > Nueva terminal.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Abrir la dirección local que muestre Vite (normalmente http://localhost:5173).

## Para explicar
- `Profile.jsx` es un componente reutilizable.
- `nombre` y `role` son propiedades (props) que recibe.
- `App.jsx` usa `map()` para generar cuatro tarjetas.
- `style.css` incluye estilos responsive.
